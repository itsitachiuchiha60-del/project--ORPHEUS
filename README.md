# Project Orpheus
**NASA Space Apps Challenge 2026**

Project Orpheus is an interactive, high-fidelity mission architecture dashboard that simulates the physical and financial constraints of interplanetary spaceflight. It calculates real-time Delta-V requirements using the Tsiolkovsky rocket equation and dynamically adjusts for payload mass and power constraints.

## Tech Stack
* **Backend:** Python
* **Frontend & Orbital Visualization:** Three.js (WebGL)
* **Data Sources:** NASA JPL Horizons, NSSDC, ISRO, SpaceX

## How to Run Locally
1. Clone this repository.
2. Start the local server (example using Python built-in server):
   python3 -m http.server 8000
3. Open your web browser and navigate to: http://localhost:8000
